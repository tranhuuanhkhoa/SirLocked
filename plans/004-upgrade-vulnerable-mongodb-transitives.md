## Why this matters

NuGet vulnerability audit reports a high-severity advisory in `Snappier 1.0.0` and a moderate advisory in `SharpCompress 0.30.1`. Both are transitively pulled by `MongoDB.Driver 3.5.0`. The app depends on MongoDB for auth, cases, rooms, gameplay state, and AI drafts, so dependency upgrades must be verified across build and backend tests.

## Steps

### Step 1: Choose the smallest safe MongoDB driver upgrade

Update `MongoDB.Driver` to the latest stable patch/minor version that removes the vulnerable `Snappier` and `SharpCompress` versions from the resolved graph. Prefer upgrading the driver over adding direct transitive package overrides.

**Verify**: `dotnet build SirLocked.sln` -> exit 0.

### Step 2: Handle compile compatibility

If the MongoDB driver has API changes, adjust only the affected compile errors. Keep existing collection names, global Mongo conventions, indexes, and query behavior unchanged.
